# 语音 / 手势接口（前端对接用）

更新：2026-10-30｜范围：**识别结果 → 指令** 的规则与 HTTP 接口，仿真后端已实现，前端可直接联调。
模型与板上实测见[语音手势接入基线](21-语音手势接入基线.md)；本文不重复。

口径：接口与规则 = **仿真实现 + 单元测试通过**；板上识别进程到本接口的调用链**尚未接**（见 §6）。
仿真结果只说明接口自洽，不是实机结论。

## 1. 一眼看懂

```text
识别端（板上/开发机）  ──text / label+confidence──▶  POST /api/interact/{voice,gesture}
                                                      │  词表匹配、阈值、连续 3 帧、冷却、武装开关
                                                      ▼
                                          受理 → 执行 stop/start → 写日志 interaction 事件
                                          忽略/拒绝 → 只回原因，不写日志
```

- 代码：[`src/interact/intents.py`](../../src/interact/intents.py)（纯标准库，不碰硬件）；
  仿真接入在 [`src/sim/sim_server.py`](../../src/sim/sim_server.py)；规则在 [`config/interaction.json`](../../config/interaction.json)，改规则不用改代码。
- 启动：`uv run --with 'opencv-python<5' --with numpy --with onnxruntime src/sim/sim_server.py`（[仿真模块](16-仿真模块.md)），
  壳子页面 `/sim/` 的调用清单里有“语音与手势指令”一组，可直接点。
- `POST` 要带 `X-Console-Token`（从 `GET /api/bootstrap` 取），和其它 POST 一样；不需要 `owner`，不占操作权。

## 2. 接口

| 方法 路径 | 请求 | 作用 |
|---|---|---|
| `GET /api/interact` | — | 状态：`armed`、词表、手势映射与阈值、当前手势连击 `streak`、`recent`（最近 50 条识别，含被忽略/拒绝的） |
| `POST /api/interact/arm` | `{"armed": true}` | 武装/解除。**识别端启动后默认未武装**，未武装时只有“停止”会执行 |
| `POST /api/interact/voice` | `{"text": "启动"}` | 一句识别文本 |
| `POST /api/interact/gesture` | `{"label": "palm", "confidence": 0.93}` | **一帧**手势分类结果（逐帧发，服务端累计连续帧） |

输入不合法（`text` 非字符串、`label` 不在四类里、`confidence` 不在 0–1）返回 HTTP 409 `{"error": "…"}`。
其余一律 HTTP 200，结果看 `status`：

```json
{"id": 12, "t": 1761800000.1, "source": "voice", "input": "请停止", "status": "accepted",
 "command": "stop", "preset": null, "matched": "停止", "reason": "已停止后续指令"}
```

| `status` | 含义 | 页面怎么显示 |
|---|---|---|
| `accepted` | 已受理并执行；日志里多一条 `interaction` | 绿，“已执行：stop” |
| `ignored` | 不是指令：没命中词 / 置信度低 / 连续帧未满 / 冷却中 / 该手势未绑定 / 同一句多条指令 | 灰，只在识别列表里显示 `reason` |
| `rejected` | 是指令但没执行：未武装 / 执行侧拒绝（如任务占用）/ 预设动作未接入（带 `"implemented": false`） | 红，显示 `reason` |

`id` 递增，`recent` 里按它去重；逐帧手势里“累计中/置信度低”这类噪声**不进** `recent`，只有触发、被拒绝、被冷却的才进。

## 3. 指令规则（`config/interaction.json`，草案）

**语音**（贪心 CTC 只给文本，**没有置信度**，所以 `interaction` 事件里没有 `confidence` 字段）

| 词 | 指令 | 现状 |
|---|---|---|
| 停止 / 停下 / 别动 | `stop` | 可用；任何时刻放行，不需武装，不受冷却限制 |
| 启动 / 开始 | `start` | 仿真里启动分拣任务；实机任务启停未支持，将返回拒绝 |
| 跳舞 | `run_preset: dance` | **一律 rejected, `implemented:false`**：预设动作待硬件组提供，不假装执行 |

同一句里有停止词 → 只执行 `stop`；命中多条别的指令 → 不执行（`ignored`）。命令冷却 2 s。

**手势**（`hrnet.om` 输出顺序固定：`0=fist 1=like 2=ok 3=palm`）

阈值 0.6，**连续 3 帧同一手势**才触发，一次保持只触发一次，冷却 2 s。当前只绑定 `palm → stop`；
`fist` / `like` / `ok` 的语义**需要需求方确认**，确认前一律 `ignored`。

约束：语音/手势**只能**映射到上表的固定指令，不得带关节、坐标等运动参数；这是为了让一次误识别不会产生不可预期的运动。

## 4. 日志里的 `interaction` 事件（契约已转 stable）

字段表见[日志契约](18-日志契约.md) §3，JSON Schema 已重新生成。只记**已受理**的：

```json
{"t": 1761800000.1, "event": "interaction", "source": "gesture", "command": "stop", "detail": "palm", "confidence": 0.93}
{"t": 1761800005.4, "event": "interaction", "source": "voice",   "command": "stop", "detail": "请停止"}
```

`source` 取 `voice` / `gesture`；`confidence` 仅手势有，**页面不能假定每条都有**；`detail` 是识别原文/手势标签。
读取方式同其它日志：`GET /api/log`、`/api/log/stream`（SSE）。

## 5. 前端怎么用

1. 进页面 `GET /api/interact` 画：武装开关、词表/手势表、最近识别列表。
2. 识别列表按 `recent[].status` 着色，显示 `source`、`input`、`reason`；`accepted` 的另外会出现在日志流里。
3. “武装”做成显式开关（默认关），和“实机现场确认”分开，不要互相代替。
4. 联调没有识别端时，用壳子页面或下面的命令注入：

```bash
B=http://127.0.0.1:8770; T=$(curl -s $B/api/bootstrap | python3 -c 'import sys,json;print(json.load(sys.stdin)["token"])')
curl -s -XPOST $B/api/interact/voice -H "X-Console-Token: $T" -d '{"text":"停止"}'
for i in 1 2 3; do curl -s -XPOST $B/api/interact/gesture -H "X-Console-Token: $T" -d '{"label":"palm","confidence":0.93}'; done
```

## 6. 没做 / 没验证的

- **识别端 → 本接口的调用链**：板上常驻识别进程、相机轮询、手部 ROI、音频采集都还没写；接口先定死，识别端按 §2 发就行。
- **实机**：`start` 在实机后端未支持；实机使能要现场确认，识别端不产生也不转发这个确认（[基线 §3.4](21-语音手势接入基线.md)）。
- **识别率**：仍无验收数字（手势现场单会话 71.2%、语音 1 段指令 + 1 段非指令），所以 E1/E7 只做指令旁路，不进自动分拣主通道（[基线 §3.5](21-语音手势接入基线.md)）。
- 与 F1 网关（`f1-arm-interface` 分支的 `/api/cmd`）的关系：本接口先在仿真落地；F1 合入后，`/api/cmd {cmd, source}` 与本接口共用 `intents.py` 的结果即可，`interaction` 事件格式不变。
- 测试：`tests/test_interact.py`（规则 + 仿真端点）。
