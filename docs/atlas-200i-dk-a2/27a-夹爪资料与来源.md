# DOFBOT 夹爪与整臂公开资料（带来源与证据等级）

- **日期**：2026-11-06
- **检索范围**：Yahboom 官方教程站（yahboom.net / yahboom.com）、Yahboom 官方商店博客、YahboomTechnology GitHub、第三方机器人资料站（teachers-manual、dreamingofrobots、robotindex、openelab）、GitHub 第三方 DOFBOT URDF 镜像；本机已有官方上游源码快照与 NVIDIA Isaac USD 资产做交叉核对。
- **未覆盖**：manuals.plus、device.report（Cloudflare 人机验证拦截）；GitHub API（限流），官方 repo 的 URDF 文件树未逐一打开。
- **证据等级**：`官方规格`（厂商规格表/参数页）> `官方文档表格`（厂商教程中给出的标定/对照表）> `官方模型`（厂商或 NVIDIA 发布的 URDF/USD）> `第三方`（非厂商站点/仓库）> `本机实测`（本项目在本机测得的数，不是网上资料）> `推断`（由上述数据计算，不是任何来源的直接陈述）。

## 结论摘要（5 条）

1. **官方存在一张“夹爪角度 ↔ 可夹物体宽度”对照表，可直接作为 J6 标定初值**：每 0.5 cm 一档，从 `0 cm → 180°` 到 `6.0 cm → 57°`，`6.0–6.4 cm → 0–57°`；官方示例 3 cm 方块用 `134°`。该项目实测“3 cm 物块命令 133°”与官方 134° 只差 1°，互相印证（[DOFBOT-Pi 官方教程](https://www.yahboom.net/study/Dofbot-Pi/15480)、[DOFBOT Pro 官方教程](https://www.yahboom.net/study/DOFBOT-Pro/17606/)）。
2. **官方上游 URDF 里没有夹爪**：`dofbot.urdf` 只有 5 个 revolute 关节（joint1–joint5），没有 finger link / gripper joint；项目 IK 里写死的 `0.12 m` 夹爪长度是代码常量，不是 URDF 几何（本机快照 `资料/.../dofbot.urdf`，见 [导入审计](06-官方源码导入审计.md#L22)）。
3. **夹爪不是简单 prismatic 平行夹爪**：官方 Isaac USD 里每侧手指由 3 段（`Finger_Left/Right_01/02/03`）用 revolute + spherical 关节串起来，属于铰接指/四连杆式机构；第三方 URDF 有 prismatic 与 revolute 两种简化版本，都不能直接当真实运动学（本机 USD 实测，见[表 B](#表-b模型里的夹爪定义)）。
4. **最大夹取物体宽度约 6.0–6.4 cm，但“最大开口 mm”官方没有直接给数**；厂商参数表只写 “Grasping Object Diameter Maximum 6cm”，官方角度表上限到 6.0–6.4 cm。USD 默认姿态实测两指内间距 35.9 mm、外跨 68.4 mm（第三方/官方模型，见[表 A](#表-a夹爪参数)）。
5. **整臂公开参数可交叉验证**：官方/半官方给出整机 303×135×473 mm、装配后 1.2 kg、5 自由度+夹爪、臂展 350 mm；Isaac USD 包围盒实测 135.0×302.9×467.7 mm，与尺寸声明吻合到厘米级（差异见[表 C](#表-c整臂参数交叉验证)）。

## 矛盾与缺口

**互相矛盾的说法**

1. **payload**：第三方站给出 500 g / 200 g，且自己注明 “not on Yahboom's own sheet”；Yahboom 官方规格页本次抓到的内容里没有 payload 数字。6 号舵机只有 6 kg·cm 且是塑料齿轮，500 g 属“接近极限的乐观值”。
2. **整机尺寸**：教师手册写 303×135×473，第三方资料站写 260×135×473，差 4.3 cm；Isaac USD 实测 303×135×468（与 303 口径一致，差 5 mm）。
3. **夹爪长度 0.12 m**：项目笔记称“Isaac USD 里指尖比 0.12 m 短约 1.1 cm”（≈109 mm），本次 USD 实测 J5 轴线→最高指尖为 117 mm（短 3 mm）。两者不一致，**可能因为“指尖”指最高点还是指夹持接触点**；需要明确 TCP 定义后再定论，不能直接采信任一数字。
4. **夹爪指尖中点偏离 J5 轴线**：项目实测约 1 cm，USD 默认姿态实测 y 向仅 ~3 mm（x 向中点 −0.7 mm）。张开/闭合状态不同可能造成差异，但 1 cm 与 3 mm 差距较大，需复核测量基准。
5. **夹爪 joint 类型**：第三方 URDF 用 prismatic（两段串联），另一第三方与官方 USD 用 revolute 三段指；网上不存在统一的“DOFBOT 夹爪运动学”。
6. **6 号舵机电压**：官方表写工作电压 4.8–6.0 V，却把堵转电流标成 “at 7.4V”；本机按 6 V 使用。原文如此，记录不改写。

**没查到的**

- 夹爪**最大/最小开口的官方毫米数**（只有“可夹 6.0–6.4 cm 物体”）。
- 手指长度/厚度的官方数值（本文只有 ISAAC USD 网格实测）。
- 手指/指垫材质、摩擦系数、实际夹持力（N）。
- 官方 DOFBOT Pi / Pro / SE GitHub 仓库里 URDF 是否含 gripper joint（API 限流，未核实）。
- 任何“J6 角度 ↔ 开口宽度”的**第三方论文/标定数据**（只找到官方角度表；第三方博客均为部署/校准经验，无开口宽度数据）。
- DOFBOT ESP32 / Arduino 版本夹爪是否与 Pi/Pro 完全相同（本次未找到该版本的夹爪规格页）。

## 对本项目建模的可用结论

1. **用官方角度表作为 jaw 宽度曲线初值（置信度：高；用途：夹爪宽度曲线初值）**。它给的是“物体宽度 ↔ 舵机角度”，不是“开口宽度 ↔ 角度”；建模时按 `开口宽度 ≈ 物体宽度 + 2×指面间隙`，间隙需实测。
2. **3 cm 物块：官方 134°，本项目命令 133°（置信度：高；用途：交叉验证 + 回归测试断言）**。差 1°，说明本机的 0–180° 角度语义与官方一致（角度越小开口越大）。
3. **不要把回读角当真实开口（置信度：中；用途：抓取判定/容差设计）**。命令 131–133° 时接触读回 124–127°，约 4–9° 的“软差”来自塑料齿轮与舵机柔顺；用回读角反推开口会系统性偏小。
4. **最大可夹物体按 6.0–6.4 cm 设上限，实际开口按 68 mm 量级（置信度：中；用途：抓取可行性筛除）**。超过 6.4 cm 官方明确会损坏 6 号舵机；本项目 3–4 cm 垃圾块在安全区。
5. **`0.12 m` 夹爪长度是偏大的固定值（置信度：中；用途：TCP/落点 z 修正）**。URDF 无夹爪、USD 实测 J5→指尖 117 mm，0.12 m 至少高估 3 mm；建议改成参数 `gripper_len` 并给 0.109–0.117 的区间做敏感性分析。
6. **夹爪按“固定工具 + 一个开合自由度”建模即可（置信度：高；用途：仿真/IK 结构）**。真实机构是 3 段铰接指，但对外只暴露 1 个舵机；除非要做接触力/自碰撞，不必复刻 6 个指关节。
7. **开口 ∝ 角度只在局部近似线性（置信度：高；用途：插值方式）**。官方表整体是 S 形（0–10% 段缓、中段陡、末端饱和），建议分段线性插值而不是单条直线。
8. **手指几何可直接用 USD 网格值（置信度：中；用途：指尖碰撞盒/抓取深度）**：远端指节约 16×6×55 mm、近端约 36×14×41 mm；指尖到 J5 轴线 117 mm。
9. **6 号舵机是塑料齿轮 + 1.7 A 堵转（置信度：高；用途：安全边界/动作时长限制）**。持续顶住物块会打齿；抓取动作应留 2–3° 余量、接触后立即停止加力（与官方 “Do not set excessive angles” 一致）。
10. **不同版本共用同一张角度表（置信度：中；用途：选型对照）**。DOFBOT-Pi 与 DOFBOT Pro 教程中的表格逐字相同，说明二者夹爪机构/舵机一致；SE/ESP32 版本未核实，引用时不要外推。
