# Atlas 200I DK A2 机械臂套件工作区

更新：2026-10-11。这里是后续开发的统一入口。指向 `资料/` 和 `data/` 的链接只在持有这些目录的机器上能打开，它们不入库；模型与物块贴面从 [Release assets-v3](https://github.com/anweat/vision-robot-arm-sorting/releases/tag/assets-v3) 取回，步骤见[根 README](../../README.md)。`资料/`保存原始课程、模型、示例和官方归档；`docs/`记录可追溯的事实、实测结果和开发方案。**资料存在、官方样例可运行、当前这台设备已验证**是三个不同状态。

## 项目目标与边界

当前课堂项目约 14 周，常规实物验证每周约 2 小时。基础任务是识别四个贴有垃圾图案的积木，定位、抓取并分类投放。第一优先级是可靠的识别和抓取闭环；多目标排序、未知类拒绝、抓取验证与重试、可视化统计属于后续扩展。新增传感器或机械结构需要讨论确认。

课程原始需求中的“颜色积木分拣”和“垃圾分拣”有交叠，但**颜色标签不等于垃圾类别**。开发时须为当前四张贴纸建立独立的标签、数据集和投放规则，不能直接把旧 `coco_names.txt` 中的 Blue/Green/Red/Yellow 当作垃圾分类模型。

## 工作区约定

```text
资料/原始解压/              原包，保留来源结构
资料/展开资源/              内层压缩包的模型、Notebook、STL
资料/课程说明/              课程离线页面、原始 JSON、任务代码片段
资料/官方资料/              官方 PDF、依赖包、Arm_Lib 和固定版本 ROS 2 源码
docs/atlas-200i-dk-a2/      本项目导航与开发基线
docs/hardware-test-results/  实机测试原始结果
scripts/                    资料盘点和受控硬件诊断脚本
```

课程和官方示例属于**参考代码**，其中有顶层运动指令。后续应用代码应进入独立的 `src/`、`config/`、`tests/`，先做离线视觉与状态机验证，再逐项接设备。每台机械臂的相机、关节、夹爪标定参数单独版本化，不把示例中的固定角度当成通用安全配置。

## 当前已确认与待确认

- **已实测**：2026-09-18 板卡 SSH、USB 摄像头 640×480 取帧、NPU 健康、`Arm_Lib 0.0.5`、I²C-7/`0x15`、RGB/蜂鸣器命令、六舵机批量小步动作与回读。1–5 号单舵机写入后回读不变化；详见硬件测试记录。
- **语音与手势 OM 已上板实测通过（2026-10-16）**：本机 WeNet `offline_encoder.om` 已核实为官方 Atlas 200I DK A2 语音样例模型（与官方包 SHA-256 逐字节一致，OM 内为 `Ascend310B1` + CANN 6.2.RC1），10 轮识别文本一致、推理中位 121.0 ms；手势 `hrnet.om` 同为 `Ascend310B1`，输出 `[1,4]`（4 类）、中位 9.07 ms、与 ONNX argmax 一致。**识别率仍未测**；见[语音与手势模型调研](19-语音与手势模型调研.md)与[硬件实测](../05-板卡连接与硬件实测.md)。
- **本地有文件，尚未实测**：YOLOv5、PFLD 的 OM/ONNX/PTH，流水线 Notebook，运动学 `.so`，STL。
- **官方源码已归档，尚未在当前板复现**：绕过代理后取得 `ros2_robot_arm` 固定提交 `9d10827572019127aa2956a58f0b570e3c8cd99b`，包括五个 ROS 2 包、URDF、相机标定、NPU 推理及分拣/堆叠代码。上游不包含 OM 模型；详情和限制见[导入审计](06-官方源码导入审计.md)。
- **第一阶段已实测跑通（2026-09-26）**：只用腕部相机扫描，按地图码自动注册，用项目自训的四类检测器（v3，YOLOv8n）识别贴纸面朝上的物块，按类别抓取并放到地图格。扫描→识别→抓取→放置→核对扫描全流程完成，四块最终距格中心 0.2–0.8 cm，详见[硬件实测](../05-板卡连接与硬件实测.md)末节。这是一次演示，**不是成功率统计**；推理当时在 Mac 上用 ONNX 运行。
- **第二阶段已确认的方向**：推理必须在板上 NPU 运行；投放改为实体容器；扩充真实垃圾种类；用多视角几何（可见外壳 + 按不确定性补拍）识别并抓取非方块物体。建议顺序见[实施基线](04-实施基线.md)。
- **项目缺口**：
  - v3 模型的 `.om` 转换和板上推理。
  - 多轮随机摆放的成功率统计。
  - 抓取失败重试、放置后自动核对、格子被错类物块占用时的处理。
  - 容器投放。
  - 非方块物体的几何重建。
  - 夹爪开口宽度曲线。
  - 急停语义。
