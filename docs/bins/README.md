# 亚克力分类垃圾桶 · 打版包（插板式 / v1 / 图号 BIN-ACR-01）

状态：**设计值，尚未加工、未实测**。日期 2026-10-23，版本 A（首版打版）。
结构：**插板式**——底板开 8 个 14×2 通槽，侧板两端做 14×2 插舌，插到底后与底板下表面平齐，再涂亚克力溶剂胶。取消浅雕工艺，DXF 只有 `CUT` 层。
几何依据：[实体容器选型约束](../atlas-200i-dk-a2/12-实体容器选型约束.md)。运行配置：`config/bins_acrylic_v1.json`。

> **2026-10-30**：桌面只有 A4 长边宽，四桶布局放不下，先做两类的双桶方案，见 [24](../atlas-200i-dk-a2/24-垃圾桶建模与仿真联调.md)；双桶贴纸页 `bins_acrylic_v2_pair_stickers_A4.pdf`（厨余、有害，内容与本包的 2、3 号相同）。已切好的板不用重切。

## 2. 设计参数（t = 2.0 mm）

| 项目 | 数值 | 说明 |
|---|---|---|
| 内口 / 外廓 | 80×80 / 84×84 mm | 3 cm 物块投放，留足落点误差 |
| 壁高 / 总高 | 40 / 42 mm | 总高不含防滑垫；侧板总高 42（含插舌段） |
| 底板 | 94×121×2 mm | 三边留边 5，耳板侧 32；开 8 个 14×2 通槽 |
| 侧板 | 82×42×2 mm | 每桶 4 块，四块相同；两端 14×2 插舌，中间底边上移 2（缺口 54×2） |
| 槽宽 / 插舌高 | 2.0 / 2.0 mm | 默认均等于板厚 t；槽宽可用 `--slot-mm` 单独调 1.9–2.1；插到底与底板下表面平齐 |
| 数量 | 4 桶/套 | 底板 4 + 侧板 16；建议多切 2 块侧板备用 |
| 定位码 | 3 枚/桶，20×20 mm | DICT_5X5_50；桶底 10n，耳板 10n+1 / 10n+2 |
| 耳板码中心距 | 50 mm | 码顶朝 +Y（耳板方向） |
| 单桶 / 整套重量 | ≈ 58 g / 233 g | PMMA 密度按 1.19 g/cm³ 估算 |

**板厚是主耦合尺寸。** t 变化时：侧板长 = 内口 80 + t、侧板总高 = 壁高 40 + t、插舌高 = t、槽宽默认 = t（可用 `--slot-mm` 单独调）。必须用脚本重算，不能沿用本图。

相贯关系：底板槽位按四壁足迹布置，四壁内面形成 80×80 内口，外面形成 84×84 外廓；四角两槽相接呈 L 形（单槽仍为 14×2）。

## 3. 设计自检（2026-10-23，脚本与 DXF 复核）

这些是几何/排版计算结果，不是加工实测：

- 每块底板 8 个逻辑槽（14×2）；四角各两条槽合并成一个 L 形孔（共边删除），共 4 个 L 孔；4 块侧板各 2 个 14×2 插舌；中间缺口 54×2。
- 每桶净用料 = 底板 94×121 − 8×14×2 + 4×(82×42 − 54×2) = 24 494 mm²；一套 4 桶 97 976 mm²；**最小料板 297×388 = 115 236 mm²，利用率 85.0%**（若用 300×400 标准板，81.6%）；单桶约 58 g，整套约 233 g。
- 排版外包围 297×388 mm（板列间距 4 mm、侧板阵列间距 2 mm）；**最小料板就是 297×388，无额外边料**。300×400 标准板右侧余 3 mm、上方余 12 mm。
- DXF 复核：36 条闭合 `CUT` 多义线 = 4 底板 + 16 个 L 形槽孔 + 16 侧板；包围盒 297×388；单位 mm；无 `ENGRAVE` 层。
- 耳板码：距外边 6、距壁 6、距侧边 12 mm；桶底码距内壁 30 mm；耳板码中心距 50 mm。
- 生成图自检（软件量测，非实物实测）：按相机量级缩小位图后仍检出 12/12 枚码；像素换算耳板码中心距 49.92–50.09 mm（设计 50）。
- 相邻桶中心距（规划 22 cm、J1 24°/55°/125°/156°）：1–2、3–4 为 117.6 mm，2–3 为 252.4 mm，均大于“开口 + 2 cm”的 100 mm 夹爪余量；但按板件外形计算，1–2、3–4 的**板边最近净距只有约 1.9 mm**，摆放误差须 ≤1 mm（见 §10）。

## 5. 打版与制作流程

1. **量板厚**：卡尺在 5 个点测厚。若实测不是 2.0（常见 1.8–2.2），按第 9 节重跑脚本，用新图下单/加工。
2. **核图**：确认版本 A、图号 BIN-ACR-01、日期；确认底板 8 槽、侧板两端插舌，无浅雕层。
3. **切割**：激光切割；切完检查 20 块零件、槽/舌尺寸、直角、崩边；保留保护膜。
4. **试插**：先不涂胶，四壁插舌对槽向下插到底；插舌与底板下表面平齐，内口 80 ± 0.3、外廓 84 ± 0.3、四角接缝 ≤0.3。
5. **粘接**：槽口、插舌、四角接缝涂亚克力溶剂胶；外侧贴美纹纸防溢流；室温固化 24 h。
6. **复测**：按第 8 节检查表复测；不合格的桶不要贴码。
7. **贴码**：A4 贴纸 100% 打印，先量 100 mm 校验尺；耳板条上边对齐底板外边，桶底片落入内口；码顶朝 +Y，耳板码中心距 50 ± 0.3。
8. **防滑**：底板四角贴 8×2 mm 硅胶垫；记录贴后总高与码面高，用于标定。
9. **回写**：把实测板厚、槽宽、内口、总高、码面高度写回配置与文档；实机验证后再把“设计值”改为“实测值”。

## 6. 插接与粘接要点

- 插舌在侧板两端，插槽在底板；四壁插舌对槽**垂直向下插到底**，不要斜插或敲入。
- 槽宽默认 = 板厚 t：先切一件试插；只调槽宽时用 `--slot-mm 1.9` 或 `2.1` 重出 DXF，不要改 `--thickness-mm`，否则插舌高、侧板长、板高会一起变。2 mm 侧板较软，拿取时托底。
- 四壁按 A 近边 → B 右侧 → C 远边 → D 左侧顺序插入；四角首尾相接，端面不外露。
- 每块侧板的两个插舌、中间底边与底板接触处、四角接缝都要有胶线；槽内可从底面补胶。
- 溶剂胶沿接缝毛细渗入；外侧贴美纹纸，内侧可见连续胶线即可，24 h 固化。

## 7. 贴纸打印与粘贴

- A4、哑光不干胶、**实际尺寸 100%**（打印对话框不要选“适合页面”）。
- 先量页脚 100 mm 校验尺：不足 100 mm 必须重打。
- 裁切：4 条耳板条（94×31）和 4 张桶底片（79×79）。
- 耳板条：有字一边朝外，**上边对齐底板外边**，左右与板边齐平；条高 31 = 耳板 32 − 1（靠壁留 1 mm）。
- 桶底片：字朝上，箭头朝耳板，落入 80 内口，四边各留约 0.5 mm；胶线较厚时可四周各裁小 0.5–1 mm。
- 贴前擦净、贴后刮板压平；建议多打印 1 份备用。

## 9. 重生成

脚本会同时写配置、6 页 PDF、两个 DXF、贴纸 PDF：

```bash
uv run src/tools/make_bins.py --thickness-mm <实测板厚>
```

例如实测 1.9 mm：

```bash
uv run src/tools/make_bins.py --thickness-mm 1.9 --drawing-date 2026-10-23 --revision B
```

只调插槽松紧（板厚仍 2.0）：

```bash
uv run src/tools/make_bins.py --slot-mm 1.9 --revision B
```

实测板厚与设计值不同时，建议把 `--revision` 递增（A → B），并改日期，避免加工商拿错版本。换板厚时**侧板长、侧板总高、槽宽、插舌、底板槽位、排版、DXF、贴纸位置全部一起变**，不要手工改单个文件。

代码结构：

- `src/tools/bins_core.py`：几何模型（含 `base_slots()` / `wall_outline()`）、画布/标注原语。
- `src/tools/bins_fab.py`：A3 图纸、轴测图、DXF、贴纸页。
- `src/tools/make_bins.py`：命令行、配置 JSON、可达性核对。

## 10. 已知风险 / 未验证

- **未加工、未实测**：所有尺寸是设计值；插接松紧、粘接强度、实际内口、码面高度都要打版后实测。
- **板厚公差**：标称 2.0 常为 1.8–2.2；槽宽/插舌高按实测 t 重算，否则插不进或过松。
- **插接配合**：2 mm 槽与 2 mm 插舌是名义零间隙；激光缝宽会使其松 0.1–0.2。先试切一块，只调槽宽用 `--slot-mm 1.9` / `2.1` 重出 DXF；不要用 `--thickness-mm` 调松紧，否则插舌/板高会一起变。
- **2 mm 插舌强度**：14×2 mm 插舌较小，插拔和搬运时不要单点受力；必要时把插舌加长（需改图）或改 3 mm 板。
- **激光缝宽**：按名义尺寸切，缝宽 0.1–0.2；若商家默认刀补，请按轮廓名义尺寸切。底板四角两槽已合并为 L 形孔，不再有共边/薄片；不要把它拆成两个孔分别做刀补。
- **透明反光**：透明侧壁有利于俯视核对，但可能反光；贴纸用哑光面。
- **粘接白化**：溶剂胶过量会发白；先试边角料。
- **摆放净距**：按当前 r=22 cm、J1=24°/55°/125°/156°，1–2、3–4 号桶板边最近仅约 **1.9 mm**；人工摆放误差须 ≤1 mm，否则两桶会碰。若无法保证，后续应调整 r 或 J1 使净距 ≥10 mm，并同步地图 v3。
- **40 mm 壁高**是约束里的建议上限；透明壁保留视觉核对，但实机相机能否稳定看到桶底码仍需现场确认。
- **摆放**：第 6 页的四桶布局来自上游连杆模型与软限位，仅几何核对；实机需按 [硬件安全边界](../05-板卡连接与硬件实测.md) 小步验证。
- **重量**：233 g/套为估算（密度 1.19），不含贴纸/胶/防滑垫。
- **最小料板**：297×388 是当前排版的零件外包围，零件外缘即料板边界；实际下料建议用 300×400 标准板（右侧 3 mm、上方 12 mm 余料），避免边缘崩边/夹持困难。
