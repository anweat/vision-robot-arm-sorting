## 项目目标与边界

基础任务是识别四个贴有垃圾图案的积木，定位、抓取并分类投放；硬件为 Atlas 200I DK A2 + Dofbot 六舵机机械臂 + 腕部单目相机。**颜色标签不等于垃圾类别**：旧 `coco_names.txt` 里的 Blue/Green/Red/Yellow 不能当作垃圾分类模型（[07](07-物块与贴纸类别.md)）。新增传感器或机械结构需要讨论确认。
