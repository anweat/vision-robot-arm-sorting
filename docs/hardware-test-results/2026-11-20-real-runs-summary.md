## 失败类型与处理（全部来自这两天的日志）

| 现象 | 日志关键字 | 处理 |
|---|---|---|
| 夹空（爪子合到底） | `grip missed (readback 132)` | 退开 → 重扫 → 3 cm 内同类找回 → 再抓；找不到记 missed 继续下一块 |
| 夹爪卡住（回读停在张开值） | `fingers jammed on the block` | 记一次失败尝试并退回，不再把整轮打崩（今天补） |
| 退回路径撞桶禁入区 | `path puts the fingers 0.4 cm into a bin's keep-out` | 退回前先抬 2 cm；仍被挡则记 missed 并继续 |
| 幻影块 | `only N view(s) saw it and no sticker` | 按扫描噪声跳过 |
| 类别无证据 | `no evidence: sticker not one of the model's 3 kinds...` | 跳过，不投桶 |
| 检测器投票但无颜色/标签 | `... skipped to avoid a wrong bin` | 跳过（防止黄块被投进有害桶） |
| 块放在过近区 | `17.4 cm from the base (< 17.5)` | 跳过并提示“移到 map y ≥ 11 cm” |
| J5 到限位 | `servo 5: expected 170, read 164` | 记 heartbeat refused，不致命；避免把块放纸边 |

## YOLO 单帧验证（排除扫描流程，只看模型）

2026-11-20 14:55，抓一帧腕部相机画面，单独跑 `src/vision/blocks_detector.py`（OM 后端）：

| 框 | 类别 | 置信度 | 画面里是什么 | 判定 |
|---|---|---|---|---|
| 绿 | kitchen | 0.922 | 中间偏上，胡萝卜贴纸 | ✅ |
| 红 | hazardous | 0.930 | 中间，电池贴纸 | ✅ |
| 黄（右） | other | 0.858 | 右侧黄块 | ✅ |
| 蓝（左） | recyclable | 0.484 | 蓝块，被画面边缘切掉一半 | ⚠ 正确但置信低 |
| 黄（左上） | other | 0.808 | 桌沿/纸角 | ❌ 误检 |
| 红（右下） | hazardous | 0.648 | 桶边白纸阴影 | ❌ 误检 |

- 推理耗时：**13.9 ms/帧**（`--bench 20`）
- 结论：**完整入画的块类别全部正确（0.86–0.93）**；误检都是背景（桌沿、桶边白纸），置信 0.65–0.81
- 因此流水线里“识别不到类别”不是模型能力问题，而是**扫描视角下块太小/太斜、票数凑不够**（`views < 3` 或累计 < 0.8）
- 证据图：`2026-11-20-yolo-single-frame.jpg`（标注）、`2026-11-20-yolo-single-frame-raw.jpg`（原帧）
